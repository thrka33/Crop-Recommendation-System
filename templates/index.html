About the Project

This project uses Machine Learning algorithms to recommend suitable crops based on soil nutrient levels and weather conditions. The system implements Multi-Layer Perceptron (MLP) and K-Nearest Neighbors (KNN) algorithms to classify the optimal crop for the given agricultural parameters.

🧠 MLP

Multi-Layer Perceptron is an artificial neural network that learns complex relationships between input parameters and crop categories.

📊 KNN

K-Nearest Neighbors identifies similar agricultural data samples and predicts the crop based on neighboring observations.
